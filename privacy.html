Privacy policy

Last updated: 2026-11-16.

Clipfactory is an internal tool used only by its owner to upload videos to the owner's own YouTube channels. It does not offer accounts to the public.

What data it uses

With the owner's permission through Google OAuth, it uses the YouTube Data API to upload videos and to read view counts of those videos on the owner's channels. OAuth tokens are stored only on the owner's computer.

What it does not do

It does not collect, sell or share personal data of anyone else. It does not read other users' data. It keeps no analytics or tracking.

Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.
